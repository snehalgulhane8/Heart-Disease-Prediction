# ❤️ Heart Disease Prediction

## 📌 Project Description

**Heart Disease Prediction** is a machine learning-based web application that predicts the possibility of heart disease based on user-provided health and medical parameters.

The project combines a trained machine learning model with a Python backend API and a web-based frontend. Users can enter the required health information through the web interface, and the application processes the input and returns a prediction.

This project demonstrates an end-to-end machine learning workflow, including data preprocessing, model training, model saving, backend API integration, and frontend interaction.

> ⚠️ **Disclaimer:** This project is intended for educational and demonstration purposes only. It should not be used as a substitute for professional medical diagnosis or treatment.

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/snehalgulhane8/Heart-Disease-Prediction.git
```

### 2. Open the project

```bash
cd Heart-Disease-Prediction
```

### 3. Create a virtual environment

Windows:

```powershell
python -m venv venv
```

Activate it:

```powershell
venv\Scripts\activate
```

### 4. Install dependencies

```powershell
pip install -r backend/requirements.txt
```

### 5. Start the backend

```powershell
python backend/main.py
```

## 🌐 Localhost

After starting the application, open the following address in your browser:

### 👉 http://localhost:8000

You can also use:

### 👉 http://127.0.0.1:8000

## 🧠 Machine Learning Model

The project uses a trained machine learning model to generate heart disease predictions.

The model-related files are stored inside the `model/` directory:

```text
model/
├── heart_model.pkl
├── scaler.pkl
├── features.pkl
└── train_model.py
```

The model can be retrained using:

```powershell
python model/train_model.py
```
